## Project Overview

This project implements an end-to-end, production-grade **MLOps pipeline** for heart disease prediction. It covers the complete machine learning lifecycle—from data preprocessing and model training to experiment tracking, containerized deployment and post-deployment monitoring.  

The architecture emphasizes **reproducibility, scalability and reliability**, following industry best practices and modern MLOps standards.

---

## Key Features

- **Full ML Lifecycle:** Complete process from data to deployment and monitoring.  
- **Production-Ready:** Designed for scalability, reproducibility, and reliability.  
- **Experiment Tracking:** Versioned experiments ensure transparency.  
- **CI/CD Automation:** Automated integration and deployment pipelines.  
- **Containerization:** Docker-based, infrastructure-agnostic deployment.  
- **Orchestration:** Kubernetes ensures scalable and robust deployments.  
- **Interactive User Interface:** Intuitive UI for predictions and results visualization.  
- **Validation & Monitoring:** Automatic post-deployment checks to maintain performance.
